# AgentGate 实现状态

更新时间：2026 年 11 月 13 日

## 已验证实现

- Pydantic 严格数据模型：请求、规范化请求、策略决策、审批、执行结果与审计事件。
- 文件、数据库和消息参数规范化；拒绝绝对路径、父目录跳转、原始 SQL 和未知字段。
- Viewer、Analyst、Operator、Approver、Auditor 五角色策略。
- 文件目录范围、数据库表字段白名单、软/硬行数阈值、消息域名和敏感模式检查。
- ALLOW、DENY、REQUIRE_APPROVAL 三态决策与稳定原因码。
- 文件读取、结构化 SQLite 查询、本地 JSONL outbox 三类模拟工具。
- SQLite 审批状态与追加式审计事件。
- 禁止自批；审批绑定请求摘要与策略版本；凭证有有效期且只能消费一次。
- 审批后参数篡改和凭证重放阻断。
- 审计服务在执行前不可用时 fail closed，工具不会被调用。
- 按 `trace_id` 查询有序调用链。
- FastAPI 请求、审批、批准后执行、trace 与健康检查接口；真实 Uvicorn 健康检查返回 200。
- 响应式本地演示网页：四个预设安全场景、策略结果解释、待审批队列、批准后执行和审计时间线。
- 审批列表/详情与近期审计 API，支持页面刷新后继续处理已有待审批请求。
- SQLite 持久化幂等预留与结果复用：相同主体和幂等键不会重复执行，不同参数复用同一键会被拒绝。
- GitHub Actions 双版本自动测试、90% 覆盖率门槛和前端 JavaScript 语法检查。

## 当前验证结果

执行命令：

```powershell
.\.venv\Scripts\python.exe -m pytest --cov=agentgate --cov-report=term-missing
```

结果：80 个测试全部通过，总体语句覆盖率 93%。其中 52 条来自版本化 JSON 安全用例集。

已覆盖的关键场景：

1. Viewer 读取公开文件成功。
2. Viewer 读取受限文件被拒绝，工具调用计数保持为零。
3. `../` 路径穿越在策略执行前被拒绝。
4. 结构化数据库查询成功，原始 SQL 被拒绝。
5. 超过软阈值的数据库查询转人工审批。
6. 模拟消息审批后只写入一条 outbox 记录，正文不写入 outbox 元数据。
7. 审批后修改收件人导致摘要校验失败。
8. 同一审批凭证第二次使用被识别为重放，工具不再次执行。
9. 请求人不能审批自己的请求。
10. 模拟敏感信息外发被拒绝。
11. 正常调用产生有序审计事件。
12. 审计写入故障时请求被阻断。
13. 数据库请求超过硬上限时直接拒绝。
14. 未授权的消息收件域名被拒绝。
15. 错误审批 token 不能触发工具执行。
16. 已拒绝的审批不能继续执行。
17. 非 Approver 角色不能批准请求。
18. FastAPI OpenAPI 契约包含预期路由和严格请求模型。
19. 前端静态资源被正确打包并由根路由返回。
20. API 层完整跑通请求、审批、执行和审计链。
21. 待审批和已批准凭证过期都会被阻断。
22. 工具执行失败会转换为结构化失败结果，不导致网关崩溃。
23. 同一幂等请求复用既有结果且工具只执行一次。
24. 同一幂等键不能绑定不同参数，并发处理中请求采用 fail closed。
25. 幂等存储不可用时，在工具执行前阻断请求。

结构化安全评估当前结果：决策与原因码一致率 100%，受保护用例控制率 100%，误放行率 0%，基本审计字段完整率 100%，网关内部 P95 延迟 25.975 ms。详见 [安全评估报告](EVALUATION_REPORT.md)。
