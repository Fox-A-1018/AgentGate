# AgentGate 课堂演示指南

## 启动

```powershell
.\.venv\Scripts\python.exe scripts\run_server.py
```

浏览器打开 `http://127.0.0.1:8010/`。演示前先确认页面右上角显示“网关运行正常”。

## 推荐演示顺序

### 1. 正常放行

选择“正常放行”，提交 `Viewer -> file.read -> public/welcome.txt`。

预期结果：`ALLOW`，页面显示文件读取结果，审计链出现请求、策略、执行开始、执行成功四个事件。

### 2. 越权阻断

选择“越权阻断”，提交 `Viewer -> file.read -> private/secret.txt`。

预期结果：`DENY / RESOURCE_OUT_OF_SCOPE`，底层工具不会执行。

### 3. 数据量阈值审批

选择“阈值审批”，Analyst 查询 `inventory`，`limit=101`。

预期结果：`REQUIRE_APPROVAL`，请求进入页面下方待审批队列。

### 4. 模拟消息人工审批

选择“人工审批”并提交。页面下方点击“批准并执行”。

预期结果：先 `REQUIRE_APPROVAL`，批准后变为 `ALLOW`，本地 outbox 只记录正文哈希和长度，不记录正文原文。

### 5. 拒绝审批

再次提交消息请求，在待审批队列点击“拒绝”。

预期结果：请求状态变为 `DENIED`，不会产生第二条模拟发送记录。

## 汇报时应主动说明

- AI 只产生候选调用，授权由确定性网关完成。
- 页面使用模拟角色，尚未实现生产级登录；这是下一阶段的明确工作。
- 100% 指当前合成测试集上的一致率，不代表能防御所有未知攻击。
- 本项目不连接真实邮箱、生产数据库或真实个人数据。

## 故障处理

- 页面无法打开：检查终端是否显示 `Uvicorn running on http://127.0.0.1:8010`。
- 页面只有空白背景：先在运行服务的终端按 `Ctrl + C`，重新执行启动命令，再在浏览器按 `Ctrl + F5` 强制刷新。页面和静态资源已设置为不使用缓存。
- 端口占用：使用 `scripts\run_server.py --port 8011`，然后访问 `http://127.0.0.1:8011/`。
- 包导入失败：确保从仓库根目录运行脚本；该脚本会自动加入 `src` 路径。
- 想清空演示数据：关闭服务后备份并删除 `data/runtime/`，下次启动会自动重建。删除前确认目录准确，避免误删其他文件。
